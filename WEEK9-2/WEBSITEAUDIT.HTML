Flower Diary — Website Improvement Report

Using Google Lighthouse

1. Introduction

This report presents a performance audit of my website, Flower Diary, using Google Lighthouse. The purpose of this audit was to evaluate how efficiently the website loads and identify possible areas for improvement.

I tested the website using Chrome Lighthouse and compared the initial result with a later test performed in Incognito mode. This helped me understand how the testing environment can affect Lighthouse scores.

2. Initial Performance Results

In my first Lighthouse test, Flower Diary received a performance score of 82 out of 100.

82 Performance
100 Accessibility
90 SEO

Initial Performance Metrics

Metric Initial Result
First Contentful Paint (FCP) 0.2 seconds
Largest Contentful Paint (LCP) 0.2 seconds
Total Blocking Time (TBT) 420 ms
Cumulative Layout Shift (CLS) 0
Lighthouse displayed a warning that Chrome extensions could negatively affect the performance test. Therefore, the initial score may not represent the website's performance under clean testing conditions.

3. Issues Identified

The initial test showed a Total Blocking Time of 420 ms. This was the main metric that stood out compared with the other recorded loading metrics.

However, Lighthouse also warned that browser extensions might affect the result. Because of this, I could not confidently identify the 420 ms blocking time as a problem caused by my website's code.

The later Incognito test helped me check the website without the same browser extension environment.

4. Improvements and Testing

Instead of making unnecessary changes to the website, I repeated the Lighthouse test in Incognito mode. This provided a cleaner testing environment and helped me check whether the first result was affected by browser extensions.

I also improved the website's SEO by adding a meta description to the HTML head section after identifying that it was missing in the initial SEO audit.

The meta description improvement was related to SEO, not a confirmed performance optimization.

5. Final Lighthouse Results

After testing the website again in Incognito mode, Lighthouse reported a score of 100 in all three categories.

100 Performance
100 Accessibility
100 SEO

These results show that Flower Diary achieved excellent Lighthouse scores in the final test.

6. What I Learned

  • Lighthouse scores can be affected by the browser environment and installed extensions.
  • Testing in Incognito mode can help reduce interference from browser extensions.
  • Performance, accessibility, and SEO measure different aspects of a website.
  • It is important to understand the actual audit results before changing website code.

7. Conclusion

Through this performance audit, I learned how to use Google Lighthouse to evaluate my website and understand its performance results.

Flower Diary achieved a final Lighthouse score of 100 in Performance, Accessibility, and SEO during the Incognito test.

This audit also taught me that testing conditions matter when evaluating a website. Overall, the process helped me better understand website quality and the importance of testing before making improvements.
